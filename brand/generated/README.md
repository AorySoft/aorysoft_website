# AorySoft logo files (generated)

Every file here is written by `web/scripts/build-brand-assets.mjs` from the
committed geometry and theme tokens. Do not edit them by hand; change the
source and rebuild:

```bash
cd web
node --experimental-strip-types --import ./scripts/register-app-loader.mjs scripts/build-brand-assets.mjs
```

| Source | What it defines |
|---|---|
| `web/src/components/brand/markGeometry.ts` | the A mark, traced from `brand/aorysoft-logo.jpg` |
| `web/src/components/brand/wordmarkGeometry.ts` | "AorySoft" in Bodoni Moda (opsz 11, wght 500, +0.03em), outlined |
| `web/src/components/brand/lockup.ts` | how mark and wordmark sit together |
| `web/src/theme/themes.ts` | `MARK_GRADIENT` and the ink colours |

The same script also writes the favicon (`web/src/app/icon.svg`), the touch
icon (`web/src/app/apple-icon.png`) and the manifest icons
(`web/public/brand/icons/`). In the site itself, use `<Logo>` from
`web/src/components/brand/Logo.tsx` rather than these files.

## Files

`aorysoft-{variant}-{tone}-{background}.svg`

| Part | Values |
|---|---|
| variant | `horizontal`: mark and wordmark in a row (default, for nav bars, headers, documents) · `stacked`: mark centred above the wordmark (square spaces, splash, merch; matches the original logo) · `mark`: the A on its own (avatars, favicons, small spaces) · `wordmark`: type only (when the mark is already present nearby) |
| tone | `color`: official blue→cyan gradient mark, wordmark in ink · `mono`: everything in one ink colour (single-colour print, embossing, busy photos, fax-grade contexts) |
| background | `on-dark`: light ink (Blackline `ink`) for dark grounds · `on-light`: dark ink (Vellum `ink`) for light grounds |

All files have transparent backgrounds. The primary presentation is
`horizontal` or `stacked`, `color`, `on-dark`, on black.

## Clearspace

Keep clear space on every side equal to the height of the A's **crossbar
foot**: the horizontal bar at the base of the right stroke (9 of the mark's
38 units, about a quarter of the mark's height). Nothing (text, edges,
other logos) enters that zone. For the wordmark on its own, use half its cap
height.

## Minimum sizes

| Variant | Screen | Print |
|---|---|---|
| horizontal | 20 px tall | 6 mm tall |
| stacked | 48 px tall | 15 mm tall |
| mark | 16 px tall | 4 mm tall |
| wordmark | 12 px tall | 4 mm tall |

Below these sizes the wordmark's hairlines break up; use the mark alone.

## Don'ts

- Don't redraw, retype or substitute the wordmark with live text in another font.
- Don't recolour the gradient, add stops, or apply the gradient to the wordmark.
- Don't add glows, drop shadows, outlines, bevels or glass effects.
- Don't stretch, skew, rotate or change the mark/wordmark proportions or spacing.
- Don't put the colour logo on mid-tone or busy backgrounds; use `mono` instead.
- Don't use `on-dark` files on light grounds (or the reverse).
- Don't place the mark inside another shape, except the square app icons generated by the script.
